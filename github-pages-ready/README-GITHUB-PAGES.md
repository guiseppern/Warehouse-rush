# Warehouse Rush - GitHub Pages ready

This folder is the static version of Warehouse Rush.

To publish it:

1. Create or open the GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open Settings > Pages.
4. Select Deploy from a branch, then choose the branch and root folder.
5. Open the GitHub Pages URL after deployment.

The repository root must contain `index.html` and `assets/`.

Do not upload the source project instead if you want a no-build publication.
